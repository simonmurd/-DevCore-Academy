2 Ringkasan Teori: Struktur Core & Semantik HTML5 Modern

W3C Recommendation Standard

HTML (HyperText Markup Language) menggunakan tag, elemen, dan atribut untuk menyusun arsitektur web. Deklarasi <!DOCTYPE html> memberitahu browser bahwa dokumen ditulis dalam standar HTML5.

Pemetaan Tag Utama & Fungsi Semantik Sintaks Wajib & Tag Teks Semantik
Tag / Elemen Kategori & Fungsi Contoh Penulisan Dampak pada Browser / SEO / Accessibility
<!DOCTYPE html> Deklarasi Tipe Dokumen <!DOCTYPE html> Mencegah browser masuk ke Quirks Mode.
<meta charset="UTF-8"> Metadata Karakter <meta charset="UTF-8"> Memastikan simbol, huruf aksen, dan emotikon tampil rapi.
<meta name="viewport"> Metadata Responsif Layout <meta name="viewport" content="..."> Mengatur skala layar otomatis di smartphone.
<h1> - <h6> Hirarki Judul / Heading <h1>Profil Utama</h1> Menentukan hirarki isi bagi SEO & Screen Reader. (Max 1 <h1>).
<img> & <a> Gambar & Tautan Hyperlink <img src="..." alt="..."> / <a href="..."> Menampilkan foto visual & navigasi antar halaman atau email.
<ul> & <li> Daftar Tanpa Urutan (Unordered List) <ul><li>Item</li></ul> Mengelompokkan poin keahlian/menu secara terstruktur.
