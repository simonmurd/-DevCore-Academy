Membuat Game Mobile!

Halo, Game Developer! 🛸 Hari ini kita akan menggunakan JavaScript dan HTML Canvas untuk membuat game UFO interaktif yang didesain khusus untuk layar sentuh HP (Mobile).

Di editor kode sebelah kanan, terdapat 20 Tugas (🎯 TUGAS 1 - 20) yang menunggu untuk kamu selesaikan agar tombol D-PAD virtualnya berfungsi.

🎯 Cara Mengerjakan:
Cari tulisan 🎯 TUGAS di dalam editor kode, baca instruksinya, lalu ubah nilai atau kodenya. Setelah itu, klik tombol "✨ Jalankan Kode" untuk menguji game buatanmu!
